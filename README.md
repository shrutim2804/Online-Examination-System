# 🎯 Online Examination System

A comprehensive Java Swing-based desktop application for conducting online examinations with MCQ questions, timer functionality, and automatic result calculation.

## 📋 Features

- **Secure Login System** - User authentication with credentials
- **Exam Instructions** - Detailed guidelines before starting
- **10 MCQ Questions** - Java programming concepts
- **Timer** - 10-minute countdown timer
- **Mark for Review** - Flag questions to revisit later
- **Auto-Scoring** - Automatic result calculation
- **Result Display** - Shows score, percentage, and feedback

## 🚀 How to Run

### Prerequisites
- Java JDK 8 or higher installed
- Windows/Linux/Mac OS

### Steps to Run

1. **Download the JAR file** from the `dist` folder

2. **Run using command line:**
   ```bash
   java -jar OnlineExamSystem.jar
